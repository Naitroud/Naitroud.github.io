# v20 — состав систем

Шапка досье начинается у верхнего края без лишнего отступа. Латунный штрих — часть закреплённого заголовка, как в пульте; остаётся вместе с закрытием/сворачиванием при прокрутке.

Клик по затемнению за пределами картографического пульта и симулятора закрывает окно. Начало клика внутри и завершение снаружи не закрывает случайно окно. Закрытие симулятора не утверждает результат.

В досье системы «Состав системы» открывает редактор. Типы объектов: планета, звезда, газовый гигант, искусственный объект, спутник, астероидный пояс, чёрная дыра, туманность. У каждого уникальная векторная иконка, название, описание, необязательная фракция и изменяемый цвет. Выбор фракции подставляет её цвет; его можно переопределить. Карточки объектов раскрываются независимо.

Внутри объектов добавляйте места/ресурсы с названием и описанием, выбирая иконку: место, город, база, руины, шахта, минералы, энергия, вода, биоресурсы, промышленность. Их карточки также раскрываются. В редакторе можно изменять и удалять объекты/места; удаление объекта удаляет его содержимое. Состав сохраняется отдельно от исходного описания, не создаётся автоматически из лора. Поставка не содержит придуманных планет или ресурсов.

Поле objects сохраняется при редактировании системы, в JSON, черновике и ZIP. До 100 объектов системы и 100 мест/ресурсов в каждом. Исходные системы без состава остаются пустыми. Перед обновлением экспортируйте JSON черновика.

Проверены создание объекта, тип, фракция и цвет, ресурс, раскрытие, сохранение/перезагрузка, закрытие по затемнению, отсутствие отступа и неподвижность шапки на компьютере и обеих ориентациях телефона. Исходный лор и карта сохранены.
