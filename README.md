# v30 — расстановка и командование

## Перед боем
Для каждой стороны отдельно задаются бонус защиты своего арьергарда и штраф атаки в чужой арьергард. «Сторона игроков» открывает расстановку: для каждого типа кораблей во флоте задайте число в Столкновении, остаток будет в своём арьергарде. На начало боя в центре должно быть не менее ceil(30% численности всей стороны). Это проверяется перед стартом.

## Приказы раунда
Каскадный выбор: сторона игроков → только её флоты → только типы выбранного флота. «Весь флот» означает отсутствие ограничения по типу. Условие абсолютного HP: любое / < / > / = / ≤ / ≥ N. Количество 0 означает все подходящие корабли. Назначение — центр или один из арьергардов/тылов. Несколько приказов показываются компактными строками и удаляются отдельно. Первый подходящий приказ имеет приоритет для корабля; выбор по стабильному порядку на начало раунда.

Каждая пересечённая граница сектора расходует одну атаку. С несколькими атаками корабль может двигаться и использовать остаток для атак после достижения точки назначения. Приказ действует один раунд; для продолжения маршрута в следующем повторите приказ. Без приказа игроки не меняют позиции, атакуют допустимые цели. Командиры игроков не делают автоматических манёвров.

## Секторы
Центр атакует центр и арьергарды. Бонус защиты своего арьергарда действует только против атаки из центра. Из своего арьергарда разрешён огонь по чужому арьергарду со штрафом стороны; против центра и врага в том же секторе штраф не действует. Тыл атакует только тот же тыл; попасть туда нужно через соответствующий арьергард. Корабли в собственном тылу не атакуют и после трёх завершённых подряд раундов сбегают окончательно. До этого могут вернуться; выход сбрасывает таймер. Бегство не считается потерей.

## Раунды и модификаторы
Бонус атаки/защиты для всех, стороны, флота или типа кораблей действует только на следующий раунд; совпавшие области складываются. Крит определяется исходным броском. Панель предыдущего/следующего и запуска раунда закреплена вверху области боя. Цветные рамки флотов соответствуют сторонам и сохраняются в отчёте.

Полный расчёт отменяется той же кнопкой. При 50 раундах без изменений автоматический расчёт приостанавливается без определения победителя. Победа только после уничтожения/бегства других сторон. При полном расчёте введённые приказы/бонусы используются только на первом следующем раунде. Далее игроки без новых приказов атакуют, оставаясь на позициях. Утверждение записывает выбранный раунд и сохраняет численность выживших, включая сбежавших.

## Окна
Исправлены непрозрачный нижний блок прокрутки досье, расположение латунной линии слоёв, единый цвет разделителей выбора держав, отступы заголовка и закрытия картографического пульта.
