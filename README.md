# v22 — редактор порядка и состава

Шапка редактора объектов у верхнего края; один типовой шеврон справа, без нативного маркера и двойной стрелки. Свёрнутые строки компактные. Быстрая кнопка из досье убрана: доступ через пульт → «Объекты системы». Описание досье имеет видимый шеврон. Клик по затемнению редактора закрывает его без сохранения.

Перетаскивайте за точечную рукоятку слева: объект на другой объект для смены порядка; место/ресурс на объект для передачи. Карточки сохраняют раскрытие при перестановках. На телефоне/клавиатуре доступны «Выше», «Ниже» и выбор «Перенести в объект». Нажмите «Сохранить состав», чтобы применить изменения. Порядок объектов сохраняется в досье, JSON и экспорте.

Проверены реальные перетаскивания порядка и ресурса, сохранение/перезагрузка, компактность строк, шеврон описания и закрытие по затемнению на трёх размерах экрана. Перед обновлением сохраните JSON. Исходная конфигурация не изменена.
