# v19 — плавные границы и закреплённые заголовки

Слой территорий сохраняет прежнюю сетку владения/ручные правки, но отрисовка извлекает контуры, упрощает мелкие ступени и сглаживает замкнутые линии. Заливка мягкая, линия фракции светится изнутри своей территории, между областями есть тёмный разделитель. Это оригинальное оформление по принципам политической карты, не копия игровых ресурсов Stellaris. При сглаживании визуальная линия немного отступает от исходных клеток; кисть редактирует прежний слой 8px.

Шапка досье закреплена внутри его прокрутки. Закрытие, сворачивание и латунный штрих принадлежат одному заголовку, не исчезают при чтении длинного описания. Сворачивание теперь скрывает также новые характеристики флота/типы кораблей и историю боёв.

Кнопки сворачивания досье, слоёв и редактора границ имеют SVG-шевроны и доступные подписи, выровнены по центру с текстом. Заголовки модальных редакторов/боевой площадки закреплены при прокрутке. Раскрывающиеся описания и истории боёв сохраняют индикаторы раскрытия рядом с текстом.

Проверено: плавные контуры; положение шапки до/после прокрутки и функциональные кнопки на 1440×960, 390×844 и 844×390; ошибок JavaScript нет. Данные объектов и границы сохранены, автоперестроение не выполняется поверх ручных правок. Перед обновлением сохраните JSON.
