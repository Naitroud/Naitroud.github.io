# v43 — редактор фракций и карточки расстановки

Исправлено обрезание содержимого пульта фракций: равные адаптивные колонки на большом экране,на телефоне последовательные блоки,все поля и сохранение доступны прокруткой.

Каждая карточка флота в расстановке содержит фракционную плашку,имя и портрет/герб командира и все его черты. Подробности черты открываются при наведении/фокусе или нажатии;окно видно поверх модального симулятора и ограничено экраном. Информация сохраняется при переносе между сторонами.

Проверены четыре размера экрана,отсутствие обрезания,подсказки и экспорт. Боевые правила и данные карты не менялись. Сохраните JSON перед обновлением.
