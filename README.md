# v28 — секторная тактика и командование

Полноценные шапки отделены от прокрутки: скроллбар расположен только ниже заголовка. Размеры окон заданы явно, без уменьшения пульта. Кнопка помощи боя — «?» рядом с закрытием.

## Поле и перемещения
Арена круглая: общее «Столкновение» в центре, вокруг для каждой из 2–6 сторон отдельные арьергард и тыл. Корабли начинают в своём арьергарде. Из центра можно перейти в любой арьергард, из арьергарда — в центр или соответствующий тыл, из чужого тыла — в его арьергард. Нельзя перескакивать напрямую в чужой тыл.

Перемещение занимает одно действие вместо атаки; каждый шаг пересекает только одну границу. При мультиатаке движение также расходует один из её слотов. Арьергард атакует центр или врагов в том же арьергарде. Центр атакует только центр. В тылу можно атаковать только находящихся там врагов. Корабль в собственном тылу отмечен отступившим и больше не действует, но может быть атакован вошедшим туда врагом. Выжившие в тылу включены в численность флота при утверждении результата. Их ранения восстанавливаются в новом отдельном бою; продление текущего боя сохраняет HP и позиции.

## Командующие
В редакторе флота целиком можно назначить командующего с именем и характером. Это влияет на выбор действий, не на характеристики:
- Агрессивный: не отступает; в 25% случаев при дальней цели сближается вместо выстрела.
- Осторожный: при HP ≤60% или объективно тяжёлом сочетании атаки/защиты противника в 80% случаев отходит на один сектор к собственному тылу.
- Уравновешенный: при HP ≤35% в 35% случаев отходит.
- Тактик: выбирает слабейшую по HP допустимую цель; при HP ≤30% в 50% случаев отходит.
- Без командующего: 18% действий пропускаются, ещё 10% вызывают случайный допустимый манёвр; остальные действия атакуют либо сближаются.

Каждый тип корабля имеет визуальную модель «Малый», «Средний», «Большой». Модель не меняет HP/атаку/защиту. Позиции и размеры юнитов отображаются на арене; тыловые уцелевшие отмечены рамкой. Журнал включает перемещения, пропуски и атаки. Предыдущий/следующий раунд восстанавливает не только HP, но и позиции. Продление воспроизводит прежнюю последовательность с тем же seed. Сохраняются криты, мультиатаки и оба режима очереди.

## Результаты
Пока сохранён прежний критерий победы: наибольшая доля сохранённого HP, включая отступивших. Поэтому полный отход сам по себе не считается поражением — это явное правило текущей версии. При равенстве ничья. В отчёте отдельно указаны выжившие, активные и отступившие. Если все живые корабли отступили, расчёт заканчивается; если остались активные противники, они могут преследовать тыловые силы через арьергард.

Старые бои не пересчитываются. Старые флоты без командира сохраняют отсутствие командира; модели по умолчанию средние. Данные сохранены в черновике/JSON/ZIP. Перед обновлением экспортируйте JSON.

Проверка: тесты двигателя на легальность атак/переходов, отступление, шесть сторон, характеры, криты/мультиатаки и seeded-продление; браузерные проверки редактора, сохранения, арены, истории и полноразмерных окон.
