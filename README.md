# Карта Вселенной — голопанель v2

Откройте index.html в современном браузере. Сервер и интернет для карты не требуются. Также предоставлен автономный файл «Карта Вселенной — голопанель v2.html» со встроенными стилями, кодом и изображениями.

## Изменения v2

- Заголовок «КАРТА ВСЕЛЕННОЙ».
- Известная Галактика оформлена отдельной областью с угловыми метками и мягким свечением. Это граница картографического обзора, не новая политическая граница.
- Вокруг — расширенное неизведанное пространство, без выдуманных галактик и систем.
- Два обзора: вся Вселенная и текущая галактика.
- Плавное движение камеры с разгоном/торможением и негромким визуально эффектом пространственного скачка на дальних перелётах.
- Ручное управление прерывает перелёт, повторный выбор меняет курс без скачка позиции.
- При системном предпочтении уменьшенного движения анимация отключается.
- Удалены служебные подписи из навигации и под описанием.

## Управление

- Перетаскивание мышью или пальцем — движение.
- Колёсико, жест двумя пальцами, +/− — масштаб.
- 0 или кнопка ⌖ — обзор Вселенной.
- G или кнопка ◎ — Известная Галактика.
- N — навигация.
- / — поиск.
- Esc — закрыть карточку/справку.
- Выбор системы/флота — карточка и плавный перелёт.
- Звезда — избранное в браузере.
- «Описание» — свернуть/раскрыть текст.

## Данные

Все данные точно совпадают с первой версией: 99 систем/регионов, 4 флота, названия, описания, ссылки, координаты и принадлежность. Изображение галактики не изменено. Имена групп сохранены, включая исходные опечатки.

Подсветка областей — консервативная растровая цветовая маска исходного изображения, не точные семантические полигоны. Слабоконтрастные пиксели могут быть пропущены, близкие по цвету пиксели фона могут попадать в маску. Новые территориальные границы не построены.

## Публикация

Для GitHub Pages поместите index.html, styles.css, universe.css, app.js и assets в опубликованную ветку, сохранив резервную копию прежней версии. Сборка не нужна. Онлайн-сайт не изменялся.

## Проверка

Chrome, 1440×960 и 390×844: промежуточные и конечные положения камеры, быстрый повторный выбор, отмена перелёта ручным вводом, уменьшенное движение, карточка на мобильном экране, поиск, избранное и флоты. Автономный HTML открыт и проверен отдельно. JSON всех объектов побайтно по значениям совпадает с первой версией. Ошибок JavaScript нет.
