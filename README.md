# v27 — исправление регрессии окон

Возвращена структура окон v25 без добавленных в v26 flex-контейнеров прокрутки. Полноразмерные формы и содержимое пульта восстановлены. Заголовки — обычная шапка с нижним разделителем, без отдельной внутренней рамки. Досье также без внутренней рамки. Шапка закреплена при прокрутке самого окна.

Сохранены кнопка справки границ в шапке и плашка E в общей помощи. Конфигурация систем, объектов, флотов, боёв и территорий не изменена. Проверены фактическая высота окон, видимость верхних/нижних действий, прокрутка и закрытие на компьютере, вертикальном и горизонтальном телефоне. Перед обновлением сохраните JSON.
