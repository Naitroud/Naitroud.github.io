# Карта Вселенной v2 — GitLab Pages

## Разместить сайт

1. Распакуйте архив. Загрузите его СОДЕРЖИМОЕ в корень репозитория GitLab: `.gitlab-ci.yml`, `README.md` и папку `public`. Не загружайте сам ZIP или лишнюю внешнюю папку.
2. Сохраните все файлы коммитом в основной ветке проекта (main, master или другая default branch). Если конфигурация CI уже есть, сохраните её резервную копию перед заменой.
3. В Build → Pipelines дождитесь успешного задания deploy-universe.
4. В Deploy → Pages откройте выданный GitLab адрес сайта.

Конфигурация уже включена. npm, Node.js, ручная сборка и указание имени репозитория не нужны. Пути относительные: работают и на отдельном Pages-домене, и под префиксом проекта.

ВАЖНО: файл `.gitlab-ci.yml` начинается с точки и может быть скрыт файловым менеджером. На Mac покажите скрытые файлы сочетанием Command+Shift+точка. При загрузке через Web IDE убедитесь, что он добавлен в корень репозитория, не в public.

## Если публикация не начинается

- В проекте должны быть включены CI/CD и GitLab Pages.
- Нужен доступный GitLab Runner. На GitLab.com включите instance runners, если они отключены. GitLab может потребовать подтверждение аккаунта или доступный лимит CI-минут.
- Если job остаётся pending, проверьте Settings → CI/CD → Runners.
- Если сайт запрашивает авторизацию, проверьте настройки доступа Pages в Settings → General → Visibility, project features, permissions. Для открытого доступа разрешите просмотр Pages всем, если политика проекта это допускает.
- На собственном сервере GitLab администратор должен настроить Pages и Runner. Архив не может включить их вместо администратора.
- Конфигурация использует современный синтаксис pages: true. Для очень старой версии GitLab требуется адаптация.

## Локальная проверка

Откройте public/index.html в браузере. Перед упаковкой сайт проверен в Chrome, в том числе через HTTP с префиксом проекта: изображения, стили, поиск системы и завершение плавного перелёта. Публикация в реальном GitLab в этой сессии не запускалась.

Лор, названия, описания, координаты и принадлежность объектов не изменены относительно v2.
