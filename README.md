# v18 — автоматические и ручные территории

Основа — приложенный пользовательский экспорт, а не прежняя сборка. Все системы, события, флоты, их параметры и лор сохранены. Подложка заменена приложенным изображением 2560×2048 без готовых политических границ; встроенные звёзды и значки самого изображения не удалялись. Координаты систем не менялись.

## Автограницы
Слой вычисляется по ближайшим системам всех фракций с радиусом влияния (по умолчанию 260 пикселей карты). События и флоты не являются опорными точками. За радиусом остаётся свободное пространство. Территории — расчётная заготовка, не доказательство принадлежности из лора. Включена и исходная группа «Нейтраные», как запрошено для всех групп. Цвета берутся из существующей конфигурации.

## Редактирование
Локальный редактор → «Редактор границ». Выберите фракцию и инструмент: кисть, ластик или камера. Кисть переносит участок выбранной фракции, поэтому пересекающихся владений нет. Ластик делает участок свободным. Радиус кисти регулируется ползунком. Камера: режим «Камера», либо Alt при перетаскивании на компьютере. Колесо масштабирует карту. На телефоне рисуйте пальцем; для перемещения переключите инструмент.

«Перестроить по системам» заново вычисляет слой с выбранным радиусом и заменяет ручные правки после подтверждения. При перемещении систем границы не перестраиваются сами, чтобы не стирать ручные изменения. «Отмена»/«Повтор» работают для последних 30 операций. «Очистить» удаляет весь слой, это можно отменить. Панель можно свернуть до заголовка. Полоса прокрутки даёт доступ к нижним кнопкам.

Границы сохраняются после каждого штриха; отдельная кнопка сохранения показывает статус. Поле territories входит в JSON, встроенные данные и ZIP. Слой «Области влияния» показывает/скрывает новые территории; множественный выбор фракций приглушает остальные.

Техническая точность кисти — сетка 8×8 пикселей исходной карты; контуры могут иметь небольшие ступени при очень близком зуме. Нет векторных узлов или редактирования отдельных вершин: корректировка выполняется кистью и ластиком.

Перед обновлением сохраните JSON. Старая резервная копия без territories создаст автослой заново. ZIP для GitHub содержит файлы в корне. Для существующего GitLab Pages с public/ размещайте файлы внутри public/, сохранив CI в корне. Сам сайт автоматически не опубликован.
