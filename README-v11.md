# Карта Вселенной v11 — стабильное досье

Описания систем, событий и флотов выровнены по ширине; последняя строка остаётся слева. Для досье всегда зарезервирована полоса прокрутки. На вертикальном телефоне развёрнутая карточка имеет постоянную высоту, независимо от длины описания. При переключении объектов уже открытая панель не запускает повторную анимацию.

Проверены позиции модели и кнопок на коротком и длинном описании: координаты и размеры совпадают на компьютере, вертикальном и горизонтальном телефоне. Прокрутка длинного текста работает. Данные, названия, описания и координаты в поставке не изменены. Черновики совместимы с v7-v10.

Публикация: содержимое ZIP в корень GitHub с заменой файлов, затем коммит. Перед обновлением сохраните JSON черновика. Автономный HTML поддерживает экспорт ZIP без интернета.
