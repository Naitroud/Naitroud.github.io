# Карта Вселенной v13

Недавнее сражение показывает уцелевших/начальных кораблей и HP каждой стороны, а также выживших, уничтоженных и начальную численность каждого участвовавшего флота. Победитель крупно выделен на боевой площадке. «Показать итог» немедленно завершает анимацию, показывает результат и кнопку сохранения.

Сражение запускается из локального редактора: выберите боевое событие, откройте редактор и нажмите «Провести сражение». В обычном просмотре функциональных боевых кнопок в досье нет. Расстановка, запуск и сохранение выполняются на редакторской площадке.

При сохранении нового результата численность каждого участвовавшего флота заменяется числом выживших, включая проигравших сбежавших/сдавшихся. Закрытие без сохранения численность не меняет. Повторная фиксация того же результата заблокирована. Если численность изменилась между расчётом и сохранением, результат отклоняется. Старые уже сохранённые отчёты v12 НЕ применяют потери автоматически задним числом.

Флот с нулём кораблей остаётся привязан к системе/событию, отмечен крестом на карте и меткой уничтожения в досье. Он исключается из доступных для боя. В досье тип «Целый»/«Уничтоженный» определяется численностью; прежняя классификация союзный/нейтральный/противник остаётся отдельной настройкой редактора для совместимости. Досье показывает численность, HP каждого корабля, диапазоны атаки и защиты в стилизованных полях. Численность 0 допустима в редакторе и JSON. Увеличение численности вручную снимает метку уничтожения.

Слои позволяют выделить несколько фракций одновременно: кнопки переключаются независимо, «Все державы» выделено отдельно и сбрасывает выбор. Несоответствующие маркеры систем, событий и флотов приглушаются; политические границы растра не изменяются.

Краткое описание системы — отдельное поле редактора (до 600 символов). Оно показывается только при наведении мышью на маркер под названием системы; в досье не отображается и при выборе кликом подсказка закрывается. Старые системы имеют пустое краткое описание. Поле сохраняется в черновике, JSON и ZIP.

Перед обновлением сохраните JSON. Публикация — содержимое ZIP в корень GitHub, с заменой файлов. Локальные изменения не становятся общими до публикации. Поставка сохраняет исходный лор и координаты.
