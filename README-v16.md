# Карта Вселенной v16

После анимации боя доступны предыдущий/следующий раунды, результаты на выбранном раунде и «Утвердить раунд N». Фиксация обновляет число выживших по каждому типу кораблей именно на выбранном раунде. Просмотр не применяет потери до утверждения. Продление добавляет 1–100 раундов к полному рассчитанному бою (а не к просматриваемому раннему раунду). Общий предел 1000 раундов. Сохранённый seed и исходный состав воспроизводят тот же префикс бросков: уже рассчитанные раунды не меняются. При отсутствии противников продолжение отключено.

Все утверждённые бои сохраняются в истории события, каждый результат сворачивается/раскрывается независимо. Последний открыт по умолчанию. Старый единичный отчёт автоматически становится первой записью при новом бое. История хранит победителя, утверждённый раунд, выживших/потери по сторонам, флотам и типам кораблей. Полный покадровый расчёт доступен на текущей площадке до закрытия; в историю сохраняется утверждённый итог, а не все промежуточные раунды.

В редакторе флота добавляйте 1–20 типов кораблей. Каждый имеет название, количество, HP, диапазоны атаки и защиты. Численность флота равна сумме типов (максимум 500); в бою до 1500 единичных кораблей. Старый флот без типов рассматривается как один «Основной тип», параметры сохраняются. В досье отображаются отдельные типы и их характеристики; общие поля отсылают к ним.

Критическое попадание: бросок равен верхнему порогу атаки — всегда 1 урона, даже если защита выше. При фиксированном диапазоне (например 5–5) каждый бросок критический. Крит не увеличивает урон сверх 1.

После утверждения выжившие типы сохраняются отдельно; уничтоженные типы имеют 0 кораблей. Новый самостоятельный бой, как ранее, начинается с полного HP каждого уцелевшего корабля — ранения между разными боями не переносятся. Продление текущего боя сохраняет все ранения.

Перед обновлением сохраните JSON. Формат черновика совместим, новые shipTypes и battles поля сохраняются в JSON и ZIP. Исходный лор не изменён.
