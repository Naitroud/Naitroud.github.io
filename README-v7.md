# Карта Вселенной v7 — события

Добавлен самостоятельный тип «Событие»: координаты, название, описание, принадлежность и произвольный цвет. У события особый ромбовидный знак с энергетическим импульсом. Доступны создание, правки, перенос, удаление, поиск, избранное и фильтр «События».

«Верхний фронт» переведён из систем в события. Сохранены id 4, исходные название, описание, координаты и все четыре связанных флота. В исходной поставке: 98 систем/регионов, 1 событие и 4 флота. Другие точки не переклассифицированы.

Флот размещается у системы или события: редактор показывает оба типа в списке дислокации. При перемещении родителя флоты следуют за ним; при удалении родителя связанные флоты удаляются после подтверждения.

Хронология «638 тонг (2370 год)» оформлена отдельной рамкой, с подписью «от Основания Галактической Ассамблеи». На телефоне показана отдельной компактной строкой под названием карты.

Все правки локальны до экспорта ZIP и публикации на GitHub. Черновики v7 содержат системы, события и флоты. Импорт v6 переводит Верхний фронт в событие с сохранением связей; добавочные черновики v4-v5 поддерживаются. Перед обновлением сохраните JSON текущего черновика.

Для публикации загрузите содержимое архива в корень репозитория GitHub с заменой файлов. Pages: main → /(root). Автономный HTML содержит все ресурсы и поддерживает ZIP-экспорт без интернета.

Проверены создание/цвет/изменение события, перенос флота между событием и системой, четыре флота Верхнего фронта, перемещение события со связанными флотами, каскадное удаление, сброс, миграция JSON v6, фильтр событий, перезагрузка и открытие экспортированного ZIP. Рамка даты проверена на компьютере и телефоне. Онлайн-репозиторий не изменён.
