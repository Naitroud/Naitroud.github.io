# Карта Вселенной v4 — локальный редактор

## Открыть редактор
Нажмите ✎ в верхней части карты. При первом входе задайте собственный логин и пароль (от 8 символов). Они действуют только в этом браузере на этом адресе. Пароль не отправляется на сервер: хранится соль и PBKDF2-SHA256 хеш. После перезагрузки редактор заблокирован.

Это НЕ серверная защита и НЕ общий администратор сайта. Любой посетитель может настроить собственный локальный редактор. Опубликованный сайт он не изменит: для этого нужен доступ к репозиторию GitHub. Локальную блокировку можно обойти через инструменты браузера. Не используйте важный пароль от других сервисов. Сброс входа — удаление ключа ugalaxy-local-lock-v4 в локальном хранилище этого сайта; при очистке всех данных сайта теряется и черновик, поэтому сначала экспортируйте JSON.

## Создать систему
✎ → Создать систему → название, описание, принадлежность, координаты и столичный статус. Кнопка «Выбрать место на карте» позволяет указать точку в существующей галактике. Перетаскивание не считается выбором точки. Новые объекты появляются на карте и в поиске сразу.

## Создать флот
Выберите систему, затем ✎ → Создать флот. Укажите название, описание, систему размещения и тип флота. Можно разместить несколько флотов у одной системы.

## Правки
Новые объекты можно изменять и удалять, включая объекты из ранее экспортированных версий. При удалении новой системы удаляются связанные новые флоты, после подтверждения. Исходные 99 объектов и 4 флота доступны только для чтения. Территории не дорисовываются.

## Сохранение и публикация
«Сохранить в черновик» сохраняет только на текущем устройстве/браузере/адресе. Черновик не виден другим пользователям. Экспорт JSON — резервная копия новых объектов, без логина и хеша. Импорт заменяет локальный черновик после подтверждения.

«Экспорт для GitHub Pages» скачивает ZIP с актуальной картой и всеми необходимыми файлами. Распакуйте ZIP, загрузите содержимое в корень репозитория с заменой файлов, сохраните коммит. GitHub Pages: main → /(root). После публикации новые объекты видны всем. Пароль, соль, хеш и локальные настройки входа в экспорт не включаются.

Экспорт ZIP работает на HTTPS-сайте, localhost или в предоставленном автономном HTML. Если модульный index.html открыт напрямую с диска, браузер может блокировать загрузку файлов для ZIP: используйте автономную версию или опубликованный сайт. Автономная версия содержит ресурсы для повторного экспорта без интернета.

Перед публикацией следующей версии сохраните JSON черновика. Старый локальный черновик может отличаться от новых опубликованных данных. Кнопка «Отменить локальные изменения» возвращает загруженную опубликованную версию и удаляет черновик, но не локальный вход.

## Проверено
Создание системы и флота, локальный вход и отказ при неверном пароле, сохранение после перезагрузки, выбор координат кликом, изменение, удаление связанных новых флотов, импорт/экспорт JSON, готовый ZIP и открытие экспортированной карты в новом браузерном контексте. Исходные тексты и координаты сохранены. Онлайн-репозиторий не изменён.
