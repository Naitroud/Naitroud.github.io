# Карта Вселенной v5 — редактор без пароля

Нажмите ✎ в верхней панели: редактор открывается сразу. Логин, пароль и блокировка удалены. Помощь и редактор размещены отдельными кнопками общей панели.

## Работа
- Создавайте системы с названием, описанием, принадлежностью, координатами и столичным статусом.
- «Выбрать место на карте» — нажмите точку внутри Известной Галактики. Перетаскивание перемещает камеру, но не выбирает координаты.
- Создавайте флоты с системой размещения, типом и описанием.
- Выберите новый объект → ✎ → Изменить/Удалить. Исходные 99 объектов и 4 флота остаются только для чтения.
- При удалении новой системы связанные новые флоты удаляются после подтверждения.
- Черновик сохраняется только в текущем браузере. Черновики v4 совместимы с v5.
- JSON — резервная копия. Импорт заменяет новые объекты после подтверждения и проверки. Неверный файл не меняет карту.
- «Отменить локальные изменения» возвращает опубликованную версию.

## Публикация
Экспортируйте ZIP, распакуйте и загрузите содержимое в корень GitHub-репозитория с заменой файлов. Сохраните коммит. Pages: main → /(root). Только после публикации правки доступны другим посетителям.

ZIP-экспорт работает на опубликованном HTTPS-сайте, localhost и в автономном HTML. Модульный index.html, открытый с диска, может не иметь доступа к файлам для экспорта из-за ограничений браузера — используйте автономный файл.

## Изображение и интерфейс
Для карты отключены нативное перетаскивание картинки, выделение и контекстное удержание изображения на телефоне. Движение карты выполняется камерой. Текст в полях и описаниях остаётся выделяемым.

## Проверено
Создание систем/флотов, мобильное создание, изменение названия и описания, перенос флота в другую систему и смена типа, сохранение после перезагрузки, удаление и отмена удаления, каскадное удаление, выбор координат и отмена выбора, импорт/экспорт JSON, отказ от некорректного импорта, сброс, ZIP и повторное открытие. Непересечение кнопок проверено на 1440×960, 390×844, 320×640 и 844×390. Нативные dragstart/selectstart отменяются, перетаскивание камеры работает. Онлайн-репозиторий не изменён.
