# Карта Вселенной v8 — события и флоты

События обозначены восклицательным знаком в светящемся кольце. В редакторе события можно выбрать «Без принадлежности». При выборе фракции цвет автоматически становится таким же, как у систем этой фракции, после чего его можно вручную заменить любым цветом. При повторном открытии формы пользовательский цвет сохраняется. Снятие принадлежности сохраняет текущий цвет.

В панели слоёв есть независимый переключатель «События». Он скрывает знаки событий на карте, но не прикреплённые флоты и не удаляет данные из поиска/редактора. Для флотов по-прежнему есть свой переключатель.

Флоты выстроены рядом с родителем с экранными отступами. Значки события и флотов не перекрываются при масштабировании; мобильная раскладка учитывает увеличенные размеры кнопок.

Данные совместимы с v7. Старые v6 и добавочные v4-v5 черновики также поддерживаются. Перед обновлением сохраните JSON черновика. Изменения общие только после экспорта ZIP и загрузки на GitHub. Названия и описания в поставке не изменены.

Проверено: знак «!», снятие принадлежности, автоматический цвет фракции и ручное переопределение, отдельный слой событий, видимость связанных флотов при скрытом событии и отсутствие пересечений на компьютере/телефоне при нескольких масштабах. Автономный экспорт ZIP проверен отдельно.
