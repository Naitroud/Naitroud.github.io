# Карта Вселенной v6 — картографический пульт

Редактирование теперь доступно для всех систем и флотов, включая исходные. Выберите точку → ✎ → «Редактировать досье» или «Перенести на карте». Быстрый перенос открывает выбор координат, затем форму подтверждения; до сохранения точка не изменяется. Флот перемещается выбором системы размещения. Связанные флоты автоматически следуют за перемещённой системой.

Название, описание, принадлежность, координаты и столичный статус можно менять явно. Без правки названия сохраняется исходная Discord-ссылка. Идентификатор объекта не меняется. Новые объекты создаются как раньше. При удалении системы связанные флоты также удаляются после подтверждения.

Черновик v6 содержит полный набор систем и флотов, включая правки и удаления исходных. Хранится локально в браузере, без пароля. Черновики/резервные копии v4-v5 поддерживаются: новые объекты объединяются с исходными. Перед обновлением сохраните JSON.

Экспорт ZIP создаёт готовую карту для GitHub Pages: распакуйте и загрузите содержимое в корень с заменой файлов, затем коммит. Только после публикации правки видны всем. Импорт JSON заменяет весь черновик после проверки/подтверждения. Сброс возвращает опубликованные данные. Предыдущие локальные данные v4 после сброса также удаляются, чтобы не восстанавливались повторно.

Пульт стилизован под голокарту: карточка выбранного объекта, разделы операций и публикации, специальные кнопки переноса/удаления, отдельные секции досье/координат и дислокации флота, стилизованный импорт. Есть прокрутка и мобильная адаптация.

В этой сборке сами названия, описания и координаты не изменены. Изменения в тестах выполнялись только в отдельном браузерном контексте. Репозиторий не публиковался. Проверены исходная система с id 0, перенос, сохранность текста и ссылок, редактирование исходного флота, перезагрузка, ZIP и повторное открытие, сброс, мобильная форма.
