# Карта Вселенной v15

У «Недавнего сражения» добавлена векторная иконка скрещённых мечей. Размер canvas поля боя одинаков во время анимации и после завершения, без сжатия до 220px.

Сторона с нулём кораблей получает статус «Сокрушены» независимо от исхода остальных сторон. Этот статус также отображается в журнале для уничтоженного флота; выжившие проигравшие по-прежнему считаются сбежавшими/сдавшимися.

Потери каждого флота в досье оформлены отдельной тактической карточкой: корабельная иконка, название, уцелевшие, потерянные, вступившие в бой, полоса сохранённой численности и остаточный HP. Уничтоженный флот отмечен приглушённым красным оформлением. Данные берутся из сохранённого отчёта, не из текущей восстановленной численности. Старые отчёты совместимы.

Проверены размеры поля боя до/после завершения на 1440×960, 390×844 и 844×390; мечи, статус «Сокрушены», показатели карточек, сохранение/перезагрузка и отсутствие ошибок JS. Исходный лор не изменён. Перед обновлением сохраните JSON черновика; содержимое ZIP загружается в корень GitHub.
