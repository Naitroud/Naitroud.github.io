# Карта Вселенной v17 — подтверждаемые криты и мультиатаки

Криты по умолчанию включены. Только максимальный бросок атаки запускает подтверждение: шанс min(100, floor(верхний порог / 5) × 5) процентов. 10 → 10%, 20 → 20%, 23 → 20%. Подтверждение броском 1–100, успех при результате не выше шанса. Успех наносит 1 HP вне зависимости от защиты; неудача возвращает обычное сравнение атаки и защиты. При выключении критов все броски проверяются стандартно, без подтверждения. Настройки боя сохраняются при продлении и в отчёте.

Каждому типу кораблей в редакторе добавлены галочка мультиатаки и число атак от 2. Нет фиксированного максимума поля, но действует лимит 2 млн потенциальных атак на расчёт для предотвращения зависания браузера. Без мультиатаки одна атака. В обычном режиме все атаки одного корабля выполняются подряд за его ход, с новым случайным противником для каждой атаки. В альтернативном режиме корабль получает N отдельных ходов в общей случайно перемешанной очереди каждого раунда. Уничтоженные до очередного хода корабли его пропускают. В досье и карточках расстановки показано количество атак.

Кнопка «Помощь по бою» в заголовке симулятора доступна до/после расчёта и во время просмотра раундов. Справка описывает расстановку, очередь, броски, криты, мультиатаки, продление, утверждение, историю, ограничения и локальную публикацию.

Проверены подтверждение/отказ критов, отключённые криты, обычный урон при неудаче подтверждения, подряд/отдельные ходы мультиатак, инвариантность продления, сохранение/перезагрузка, справка и мобильные переключатели. Старые shipTypes без новых параметров получают одну атаку; старые отчёты не пересчитываются. Перед обновлением сохраните JSON черновика. Исходный лор сохранён.
