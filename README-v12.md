# Карта Вселенной v12 — тактические сражения

## Настройка
В редакторе события выберите тип «Боевое» или «Информационное». Информационное не имеет кнопки запуска боя. Старые события по умолчанию информационные, включая Верхний фронт: боевой тип задаётся вами явно.

В редакторе флота задайте параметры каждого корабля: численность, HP, минимум/максимум атаки и защиты. Значения по умолчанию: 10 кораблей, 3 HP, атака 5–20, защита 5–20. Они являются параметрами симуляции, не новой информацией лора. Разрешено 1–500 кораблей на флот, 1–100 HP, пороги 0–1000.

## Расстановка
В досье боевого события нажмите «Провести сражение». Добавьте 2–6 сторон и назовите их. Перетащите флоты из доступных на стороны либо выберите сторону в карточке флота (для телефона и клавиатуры). Доступны все флоты карты; назначение в симуляторе не меняет их дислокацию. Один флот не может находиться в двух сторонах. В каждой стороне должен быть хотя бы один флот. Всего не более 1500 отдельных кораблей в одном бою. Раунды: 1–100.

## Правила
Каждый живой корабль — отдельный юнит и действует один раз за раунд в случайном порядке. Уничтоженный до своего хода корабль не атакует. Цель — случайный живой корабль другой стороны, включая все враждебные стороны. Атака и защита — равномерные целочисленные броски в заданных включительных диапазонах. Если атака строго выше защиты, цель теряет 1 HP; равенство не наносит урон. При 0 HP корабль уничтожен.

Если осталась одна живая сторона, бой заканчивается досрочно. После лимита раундов побеждает сторона с наибольшей долей оставшегося HP к начальному. При равных долях или отсутствии выживших — ничья. Это явно выбранная трактовка «наиболее целой стороны», а не абсолютное количество оставшихся кораблей. Уцелевшие проигравшие считаются сбежавшими/сдавшимися; при ничьей такого победителя нет.

## Анимация и итог
На площадке показаны отдельные корабли, огонь и потери по раундам. Кнопка «Показать итог» пропускает только визуальную часть, расчёт остаётся тем же. Уменьшенное движение показывает результат сразу. Закрытие площадки без сохранения не меняет событие.

Нажмите «Сохранить итог в событии»: досье покажет «Недавнее сражение», победителя, число раундов, а иконка сменится на скрещённые клинки. Отчёт включает остаточный HP и потери каждого флота. Исходное описание не меняется. Численность флотов на карте НЕ уменьшается автоматически: потери записаны в отчёте; изменить численность можно редактором. Новое сражение заменяет прежний итог только после сохранения.

Результат, тип события и параметры флотов сохраняются локально, в JSON и экспортированном ZIP. Публикация для других пользователей как прежде — экспорт и загрузка содержимого в корень GitHub. Перед обновлением сохраните JSON. Старые черновики поддерживаются с параметрами по умолчанию.

## Проверка
Движок проверен на единичных кораблях, бросках, повреждениях, уничтожении, победе, ничьей, досрочном завершении, заданных раундах, воспроизводимости по seed и отказе от дублирования флота. Проверены реальный drag-and-drop, мобильная расстановка, анимированный canvas, пропуск визуальной части, сохранение и перезагрузка результата, редактирование события без потери результата, новые характеристики флота. Лор поставки не изменён; GitHub не обновлялся автоматически.
