# v24 — шапки, фокус и справка границ

Под выбором держав тонкая латунная линия. Окна с заголовком имеют единый закреплённый верхний блок и латунный штрих как в пульте, без верхнего отступа редактора. При открытии фокус ставится на окно, а не кнопку закрытия. Клавиатурная навигация Tab и её подсветка сохранены.

Command (⌘) на Mac, как Alt, временно позволяет перетаскивать карту вместо рисования территории. На телефоне выбирайте режим «Камера». В панели территорий добавлена справка с описанием кисти, ластика, автограниц, радиуса, отмены/повтора, слоёв и сохранения. Общая справка обновлена: старое утверждение об отсутствии создаваемых границ удалено.

Проверены шапки на трёх размерах, нейтральный начальный фокус, фактическое перемещение с Command без изменения территорий, справка и разделитель выбора держав. Конфигурация не изменена. Перед обновлением сохраните JSON.
