# v23 — единое редактирование системы

Быстрая кнопка с карандашом открывает редактор выбранного объекта. Если ничего не выбрано — пульт. Досье системы и состав редактируются в одной форме с общим сохранением; для флотов и событий формы остаются прежними. Отдельная кнопка состава и сворачивание пульта убраны.

В составе вместо номеров отображается тип: Планета, Звезда, Пояс Астероидов и т.д., затем имя. Кнопка «Свернуть все» переключает все объекты/места в компактный режим; повторное нажатие раскрывает их.

Перетаскивание рукояток переведено на Pointer Events, отключён конфликтующий нативный drag. Объект перемещается относительно объекта-получателя, место/ресурс переносится внутрь него. При перетаскивании получатель подсвечивается, у края окна включается прокрутка. Оставлены кнопки порядка и выбор получателя для клавиатуры/телефона. Изменения применяются общим сохранением формы, закрытие не сохраняет.

Проверены реальное перемещение мышью без программного изменения данных, перенос ресурса, единое сохранение досье/состава, перезагрузка, быстрый вход, отсутствие сворачивания пульта и сохранение редактора флота. Перед обновлением сохраните JSON.
